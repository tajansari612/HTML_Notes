Self closing tags in html

In HTML, self-closing tags (also known as void elements) are tags that do not require a separate closing tag (like or
). Because they cannot contain any text or other HTML elements inside them, they are closed within a single tag.

How They Work

In standard HTML5, you can write self-closing tags in two ways. Both are perfectly valid, and browsers will render them exactly the same: The Standard HTML5 way: (No trailing slash) The XHTML/React way: (With a trailing slash)

Note for React/JSX developers:

If you are working in React or JSX, the trailing slash (/) is strictly required, otherwise your code will throw a syntax error. In pure HTML5, it is optional and purely a matter of personal or team style.
